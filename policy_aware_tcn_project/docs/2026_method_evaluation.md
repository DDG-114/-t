# 2026 Method Evaluation

本文档记录把当前已实现方法外推到 2026 年有真实价格数据区间后的测试结果。

## 评估范围

- 测试窗口：`2026-01-01` 到 `2026-04-27`
- 评估天数：`117`
- 评估点数：`11232`
- `2026-04-28` 未纳入日精度评估，因为当天只有 1 个真实价格点。
- 2026 年已进入零地板价机制，因此预测下限按 `0` 处理；指标分母仍按项目定义使用 `max(abs(y_true), 40)`。

运行命令：

```bash
../dayahead_epf_agent_project/.venv/bin/python scripts/20_evaluate_2026_methods.py \
  --start 2026-01-01 \
  --end 2026-04-27
```

输出汇总：

```text
outputs/eval_2026/summary_2026_methods.json
```

## 数据分布

`2026-01-01` 到 `2026-04-27` 的价格分布与 2025-12 明显不同：

```text
rows: 11232
days: 117
Price <= 1:   3971 (35.35%)
Price <= 40:  4063 (36.17%)
Price >= 500:  763 (6.79%)
Price >= 800:  269 (2.39%)
Price >= 999:  181 (1.61%)
mean: 208.33
p10: 0.0
p50: 230.0
p90: 420.0
max: 1000.0
```

因此，2026 的主要挑战不再只是 2025-12 的高价边界，而是大量合法 `0` 元或近
`0` 元价格。旧模型如果仍按 2025 的 40 元下限和地板价状态学习，会系统性高估这些低价点。

## 方法结果

| 方法 | mean_daily_accuracy | MAE | RMSE | 达标天数 |
| --- | ---: | ---: | ---: | ---: |
| `deep_weather_highcap_2026` | 0.477835 | 92.010 | 154.645 | 5 / 117 |
| `gbm_residual_anchor_2026` | 0.424155 | 95.008 | 159.951 | 4 / 117 |
| `online_residual_2026` | 0.366621 | 95.434 | 161.015 | 7 / 117 |
| `deep_gbm_anchor_conservative_2026` | 0.164143 | 101.512 | 154.522 | 0 / 117 |
| `deep_gbm_anchor_residual_2026` | 0.138072 | 100.825 | 153.187 | 1 / 117 |

本轮最好的 2026 外推结果是 `deep_weather_highcap_2026`，但其日均精度只有
`47.78%`，离 85% 仍很远。

## 误差结构

以 `deep_weather_highcap_2026` 为例：

| 真实价格区间 | 点数 | 区间精度 | 相对误差占比 |
| --- | ---: | ---: | ---: |
| `<=40` 低价/零价 | 4063 | 0.347905 | 45.17% |
| `40-100` | 239 | -0.266593 | 5.16% |
| `100-200` | 829 | 0.147190 | 12.05% |
| `200-500` | 5411 | 0.650147 | 32.28% |
| `500-800` | 452 | 0.640188 | 2.77% |
| `800+` | 238 | 0.369304 | 2.56% |

最大误差来源已经变成 `<=40` 的零地板价区间，占总相对误差约 `45%`。这说明：

- 2026 测试不能继续只沿用 2025 的“40 元地板价”假设；
- 当前模型虽然有 2026 零地板价静态变量，但训练样本中真实 0 元价格不足，泛化不够；
- 在线残差校正在 2026 上没有改善总精度，说明短窗口残差会被零价/高价快速切换扰动。

## 实现修正

为避免 2026 评估不公平，已把预测下限从硬编码 `40` 改成可配置：

- `state_gbm` 支持 `model.clip_prediction_min` 和 `state_gbm.floor_override_value`；
- `residual_calibrator` 支持 `prediction_min`；
- `online_residual_calibrator` 支持 `prediction_floor` 和 `prediction_cap`。

2025 原配置不变，默认仍按 40 元下限运行；2026 评估脚本临时使用：

```text
model.clip_prediction_min = 0
state_gbm.floor_override_value = 0
online_residual_calibrator.prediction_floor = 0
```

## 结论

这些方法已经可以用于 2026 数据测试，但结果表明：2026 是一个新的零地板价分布问题，
不能直接靠 2025 的最佳模型外推解决。后续若要提升 2026 精度，应优先做：

- 2026 零价/近零价状态分类器；
- 低价状态专门残差专家；
- 用 2026 已发生月份做滚动再训练或增量校准；
- 将 2026 的真实 0 元价格保留为训练标签，而不是按旧规则清洗成缺失；
- 再考虑接入深度模型做锚定式残差，而不是从零预测完整电价曲线。
